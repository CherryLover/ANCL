# C 线准备说明

## 定位

C 线是以原作者第 319 章《关于妖族的电影》为基点的第二版续写。

- 官方基点：`A-0319`。
- 正文起点：`C-0320`。
- 当前状态：尚未开始正文。
- 首要原则：基础材料未更新完成前，不编写 C 线章节正文。

## 事实采用顺序

1. A 线已经收录的原作者正文。
2. 原稿检查记录中确认的文本事实。
3. 更新到第 319 章的状态快照、逐章摘要、信息差和阵营资料。
4. C 线近期批次大纲与场景卡。
5. B 线及其他历史推演只能作为比较材料。

## 开写前必须完成

- 第 251 至 319 章逐章摘要。
- 第 319 章人物与阵营状态快照。
- 主要人物的已知、未知与误解清单。
- 正道、魔道、妖族、散修、世家、国外势力和凡人群体的利益地图。
- 未解伏笔与不可擅自解释的设定清单。
- 第 251 至 319 章叙事结构、视角轮换和章节节奏分析。
- 第 320 章后多套近期走向比较。
- 选定方向后的首批 15 至 20 章滚动大纲。

## 规划方法

- 已确认事实作为硬约束。
- 高概率趋势只用于近期推演，不提前写成必然终局。
- 远期方向保留多个候选，不预设固定完结章数。
- 采用近细远粗：5 章场景级、20 章事件级、更远只记趋势。
- 每批正文完成后，依据新增内容重新校准后续规划。

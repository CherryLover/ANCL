# 写作准备资料

## 当前资料

- [事件脉络](./事件脉络.md)：按章节阶段整理故事发展、关键转折和当前落点。
- [世界与阵营](./世界与阵营.md)：两界设定、主要势力、信息差和冲突结构。
- [写作风格](./写作风格.md)：续写时使用的语言、节奏、人物表达和章节规范。

## 正文位置

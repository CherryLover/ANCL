# 续写对照记录

## 用途

本文件用于长期记录本工作区续写与原作者后续更新之间的关系。

续写内容保留我们在当时已有原文基础上的判断和推演。原作者发布新章节后，原文与续写同时保存，通过对照观察故事走向、人物选择和设定变化，不用其中一份覆盖另一份。

## 来源标记

- `0` 开头：原作者版本，例如 `0251_第251章 章节标题.txt`。
- `1` 开头：本工作区续写版本，例如 `1251_第251章 章节标题.txt`。
- 文件名第一位是来源标记，真实章号仍以文件名和正文中的“第 N 章”为准。
- 同一章可以同时存在 `0` 和 `1` 两个版本。

## 对照原则

原作者发布同章内容后：

1. 原样新增 `0` 开头的原文章节，不修改现有续写。
2. 记录两个版本的共同走向、主要分歧和原文新增事实。
3. 原作者明确的新设定优先作为后续续写依据。
4. 已经形成的续写线继续保留，作为独立的观察样本。
5. 是否从原文最新位置另开续写批次，单独决定，不直接覆盖旧批次。

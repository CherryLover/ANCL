# ANCL（AI Novel Continuation Lab）

ANCL 是一个 AI 小说续写研究与对照项目。本仓库当前以《我把现代文明传回了修仙界》为研究对象，整理已有原文，并尝试在保持人物、设定、风格和情节连续性的前提下续写后续内容。

## 写作目的

这个目录用于整理小说原文，并在此基础上续写后续内容，同时长期记录续写与原作者更新之间的差异。

续写的目标不是重新改写原书，也不是另起一套故事，而是接着第 250 章继续推进，尽量保持已有的人物性格、语言风格、世界规则、事件因果和阅读节奏。

## 资料采用顺序

不同资料出现冲突时，按以下顺序判断：

1. 前 250 章原文。
2. 原稿检查记录中已经确认的事实。
3. 主要人物、事件脉络、世界与阵营资料。
4. 故事总纲与长期人物弧中已经锁定的长期方向。
5. 单批章节大纲和后续设想。

原文已经明确写出的事实不能为了方便续写而随意改变。准备资料中带有推测性质的内容，可以在不违背原文的前提下调整。

## 续写基本规范

### 开始写作前

- 阅读准备续写位置之前至少三至五章，确认情节衔接和人物当时状态。
- 查看事件脉络中的未完成情节，避免长期遗忘已经铺开的线索。
- 确认本批内容属于故事总纲中的哪一卷，并检查相关人物弧应推进到哪里。
- 先规划连续五章左右的推进方向，再开始写单章正文。
- 每章明确一个主要事件、一个需要交付的信息和一个章末悬念。

### 正文要求

- 第 251 章以后继续使用纯文本文件。
- 原作者正文使用 `0` 开头，例如：`0251_第251章 章节标题.txt`。
- 本工作区续写使用 `1` 开头，例如：`1251_第251章 章节标题.txt`。
- 文件名第一位只表示来源，正文中的真实章号仍是第 251 章，不写成第 1251 章。
- 原作者以后更新同一章时，继续新增对应的 `0` 开头文件，不能覆盖或改名现有的 `1` 开头续写文件。
- 正文第一行格式：`第251章 章节标题`。
- 文件名中的章号、标题必须与正文第一行逐字一致。
- 单章建议控制在约 2200 至 3000 字，确有重要情节时可以适当增加。
- 写作风格以[写作风格](./写作准备/写作风格.md)为准。

### 连续性要求

- 不随意改变人物身份、修为、所属势力、已经建立的关系和已知秘密。
- 天衍宗目前不能向夏恒等外部修士公开蓝星和跨界秘密。
- 大夏目前不能公开告诉赵小凡，国家已经掌握他的真实来历。
- 王小彤的手机仍是大夏观察元阳界的重要渠道。
- 夏恒的隐藏机缘可以逐步暗示，不能刚登场就全部揭晓。
- 续写线中，赵小凡已开始参与疑难病例方法验证；夏恒完成渔国北境第一阶段救灾并发现一套控制粮食、药材与散修生意的隐秘账册。吕祖手稿、天衍宗建城计划和“乱局借天计划”仍未完全结束。

### 原文保护

- 第 1 至 250 章是现有原稿，未经明确决定不要直接润色、删改或重排。
- 原稿中第 143 章和第 230 章各有一处章号误写，具体情况见[原稿检查记录](./写作准备/原稿检查记录.md)。
- 写作准备资料与小说正文分开存放，不把分析、提纲或说明文字混入正文。

## 原文与续写的长期对照

- `0` 开头是原作者版本，作为后续判断人物、设定和情节的最高依据。
- `1` 开头是当前续写线，保留当时基于已有原文作出的推演。
- 原作者更新后，两条内容同时保留，不把续写改写成原文，也不拿续写替代原文。
- 每次出现同章双版本时，在[续写对照记录](./写作准备/续写对照记录.md)中记录相同点、分歧点、新增事实和后续续写需要调整的方向。

## 每章完成后的检查

- 是否接住上一章结尾。
- 是否真正推进了事件，而不是只重复人物震惊和讨论。
- 人物说话是否符合原有性格。
- 两个世界各自知道什么、误解什么，是否保持一致。
- 本章新增设定是否与前文冲突。
- 文件名、章号和正文标题是否一致。
- 章末是否给下一章留下自然的继续方向。
